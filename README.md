## 📋 Sobre o Projeto

Este é um formulário de cadastro moderno e responsivo desenvolvido para meu portfólio como Front-End Developer. O projeto demonstra minhas habilidades com HTML5, CSS3 e Bootstrap 5, aplicando conceitos de UI/UX Design e boas práticas de desenvolvimento web.

## ✨ Funcionalidades

- ✅ Campos de usuário e senha com validação de tamanho
- ✅ Checkboxes para newsletter e novidades
- ✅ Radio buttons para seleção de contato padrão
- ✅ Select com opções de profissão
- ✅ Textarea para observações
- ✅ Efeitos de hover e focus para melhor interação
- ✅ Gradiente e glassmorphism no design
- ✅ Ícones da biblioteca Bootstrap Icons
- ✅ Layout com Grid System do Bootstrap

## 🚀 Tecnologias Utilizadas

| Tecnologia | Descrição |
|------------|-----------|
| HTML5 | Estrutura semântica do formulário |
| CSS3 | Estilização personalizada e animações |
| Bootstrap 5 | Framework CSS para responsividade e componentes |
| Bootstrap Icons| Biblioteca de ícones |
| Google Fonts | Fonte Inter para tipografia moderna |

## 🎨 Design Principles

- Gradiente Vibrante: Fundo com degradê para criar profundidade visual
- Glassmorphism: Efeito de vidro no container principal
- Micro-interações: Feedback visual em hover e focus
- Espaçamento Balanceado: Uso consistente de padding e margin
- Hierarquia Visual: Títulos, subtítulos e labels organizados
- Acessibilidade: Labels associadas aos inputs e contrastes adequados

## 📱 Responsividade

O layout se adapta perfeitamente em:
- 📱 Dispositivos móveis (menos de 576px)
- 📲 Tablets (576px - 992px)
- 💻 Desktops (acima de 992px)
